# Supabase Database and Authentication

## Overview

This project uses Supabase as its backend database and authentication service.

## My Contribution

- Created and configured the Supabase project.
- Set up Supabase authentication.
- Created and configured database tables for farmer-related information.
- Configured Row Level Security (RLS) policies.
- Connected the Supabase project with the frontend application.

## Technologies

- Supabase
- PostgreSQL
- Supabase Authentication
- Row Level Security (RLS)
- JavaScript

## Database Documentation

See `schema-documentation.md` for the existing database tables and columns.

See `security-policies.md` for the configured database security policies.

## Configuration

The frontend connects to Supabase using the project URL and publishable key, configured through environment variables.

Secret keys and database passwords are not included in this repository.
